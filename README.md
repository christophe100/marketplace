# ASSIGAME Marketplace

![ASSIGAME Banner](./src/assets/logo.png)

## 📌 À propos du projet

ASSIGAME est une plateforme de marketplace moderne permettant aux vendeurs et aux acheteurs d'interagir sur une même plateforme. Les utilisateurs peuvent publier, rechercher et acheter des produits dans différentes catégories telles que les sacs, meubles, montres, chaussures, lunettes, parfums et bien d'autres.

Cette application a été conçue et développée par **Christophe Gbenin** dans le cadre de son apprentissage et de ses projets en développement Full Stack.

---

## Fonctionnalités

### Pour les acheteurs

- Consultation des produits
- Recherche et filtrage par catégorie
- Visualisation détaillée des articles
- Gestion des commandes
- Interface moderne et responsive

### Pour les vendeurs

- Publication de produits
- Gestion du catalogue
- Suivi des ventes
- Gestion des commandes

### Administration

- Gestion des utilisateurs
- Gestion des produits
- Gestion des catégories
- Suivi des statistiques

## Installation

### Prérequis

- Node.js 18+
- npm

### Cloner le projet

```bash
git clone https://github.com/christophe100/marketplace.git
cd marketplace
```

### Installer les dépendances

```bash
npm install
```

### Lancer le projet

```bash
npm run dev
```

L'application sera accessible sur :

```bash
http://localhost:3000
```
